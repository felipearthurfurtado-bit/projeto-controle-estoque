# Projeto Final - Controle de Estoque

Projeto Final da disciplina de Desenvolvimento de Sistemas para Dispositivos Móveis
(Unimontes - Técnico em Desenvolvimento de Sistemas).

## Objetivo

Aplicativo de controle de estoque feito em React Native + Expo + TypeScript.
Permite cadastrar e editar produtos com validação, organizar por categorias,
registrar entradas e saídas de estoque, alertar sobre estoque baixo e
consultar o histórico de movimentações.
Os dados são salvos localmente no celular (AsyncStorage).

## Como executar

- Para instalar o projeto

npm install

- Para executar o projeto no Expo Go (celular)

npx expo start --tunnel

- Para executar o projeto no navegador Web

npx expo start --web
